# Security Policy

We take the security of JARVIS seriously. If you believe you have discovered a security vulnerability, please report it privately and responsibly.

## Reporting a vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report the issue privately through GitHub's security reporting workflow if the repository has private vulnerability reporting enabled, or contact the maintainers through the appropriate private channel available for this repository.

When reporting, please include:

- the affected component or file
- a description of the vulnerability
- steps to reproduce it, if possible
- any relevant proof of concept or exploit details
- the impact of the issue and any mitigations already in place

## Disclosure expectations

We ask that you allow us a reasonable amount of time to investigate and address the issue before making any public disclosure.

## Scope

This policy applies to the JARVIS repository and the code maintained within it.

## Thank you

Responsible disclosure helps keep the project and its users safe.
